# Daocu Font Family (Vietnamese)

Bộ gia đình phông chữ **Daocu** (Geometric Sans-serif) được Việt hoá hoàn chỉnh đầy đủ 146 ký tự tiếng Việt với trọn bộ **6 cấp độ độ đậm (Weights)**.

---

## 🌟 Giới thiệu

**Daocu** là bộ phông chữ không chân hình học hiện đại (Modern Geometric Sans-serif), được phát triển và Việt hoá từ nguyên mẫu Aveton (Flawless and Co) theo hệ thống quy chuẩn của **Việt Font Kit (VFK)**:

- **Đầy đủ 146 ký tự tiếng Việt:** 134 ký tự có dấu + `đ/Đ` và các tổ hợp dấu kết hợp `ccmp`.
- **Hệ thống 6 Weights hoàn chỉnh:** Light (300), Regular (400), Medium (500), SemiBold (600), Bold (700), Black (900).
- **Tối ưu hình học (Optical Adjustments):** Dấu hỏi vòm tròn thanh nhã, dấu nặng tròn xoe lấy từ chấm câu gốc, chữ `g` sạch sẽ không chấm lơ lửng, nới rộng khoảng cách kerning `T + r`.
- **Chống cắt đỉnh trên Microsoft Word:** Tắt cờ `USE_TYPO_METRICS`, nâng `winAscent` chuẩn xác giúp toàn bộ dấu chữ hoa cao nhất (`Ẩ, Ẫ, Ố, Ắ`) hiển thị trọn vẹn, không bao giờ bị cắt cụt.
- **Tương thích toàn diện:** Đạt chuẩn **`KIỂM WORD: ĐẠT`** và vượt qua bộ lọc **OpenType Sanitizer (`OTS: PASSED`)**.

## 📦 Danh sách file font

Các file font định dạng OpenType CFF (`.otf`) nằm trong thư mục [`fonts/`](./fonts):

| Tên file | Cấp độ Weight | usWeightClass | Mục đích sử dụng |
| :--- | :---: | :---: | :--- |
| `Daocu-Light.otf` | **Light** | 300 | Văn bản dài, layout thanh lịch, thiết kế tối giản |
| `Daocu-Regular.otf` | **Regular** | 400 | Văn bản tiêu chuẩn, giao diện UI app/web |
| `Daocu-Medium.otf` | **Medium** | 500 | Nhãn nút bấm, sub-title, menu điều hướng |
| `Daocu-SemiBold.otf` | **SemiBold** | 600 | Phụ đề video, sub-heading, nút bấm nổi bật |
| `Daocu-Bold.otf` | **Bold** | 700 | Tiêu đề chính (Heading H1/H2), poster, banner |
| `Daocu-Black.otf` | **Black** | 900 | Headline ấn tượng, cover art, display typography |

## 🚀 Hướng dẫn cài đặt

1. Tải về thư mục `fonts/` hoặc tải toàn bộ repository.
2. **Trên macOS:** Chọn tất cả các file `.otf` trong `fonts/` → Nhấp đúp chuột → Chọn **Install Font** (Font Book).
3. **Trên Windows:** Chọn tất cả các file `.otf` → Nhấp chuột phải → Chọn **Install for all users** (hoặc **Install**).
4. Khởi động lại phần mềm đồ hoạ (Photoshop, Illustrator, Premiere, InDesign, Canva) hoặc Office (Word, PowerPoint). Toàn bộ 6 weights sẽ tự động gom chung dưới tên họ font **`Daocu`**.
